# Tooly brand assets

Place the owner-approved logo file here as `tooly-logo.png` (or SVG if you have a clean vector source).

Usage:
- Preserve original colors and proportions.
- Do not stretch, crop, redraw, or recolor it.
- Use a light/transparent variant that has enough contrast against the light UI.
- If the supplied logo contains small text or detailed app tiles, do not use it at tiny sizes; request/prepare an approved icon-only mark.
- Do not recreate official third-party product logos manually. Use provider-approved assets where allowed, or use neutral tool/category icons.
- Verify trademark, brand-guideline, and reseller requirements before public launch.
