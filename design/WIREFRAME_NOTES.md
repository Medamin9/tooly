# Wireframe Notes

## Homepage
1. Slim announcement strip (optional; only truthful current message).
2. Header: logo, categories, search, language, account/cart.
3. Hero: memorable editorial headline, short explanation, primary CTA, secondary browse action. One authored motion scene; no auto-playing full-screen 3D intro.
4. Category discovery: AI, design, video, productivity, business, developer tools.
5. Curated plans: clear duration, price, delivery method, eligibility, and availability.
6. How it works: choose → checkout → receive eligible access/instructions.
7. Trust section: explain support, payment process, and policies only with substantiated claims.
8. FAQ and footer with legal/contact links.

## Product card
- Tool/provider name and category
- Plan name and duration
- Clear price and currency
- Key restrictions/eligibility
- Availability status from backend
- Primary action
- No fake discount or crossed-out price without a real reference price

## Product detail
- Product summary
- Included features and limitations
- Duration/renewal/delivery details
- Price and tax/fee disclosure where applicable
- Refund/cancellation policy link
- FAQs/support link
- Clear add-to-cart/buy action

## Admin
- Sidebar navigation, responsive drawer on mobile
- Overview with actual database metrics
- Searchable/filterable tables
- Confirm destructive actions
- Explicit publish/draft states
- Audit history for sensitive actions
- Avoid charts until meaningful data exists
