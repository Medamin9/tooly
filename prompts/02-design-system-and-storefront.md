# Prompt 02 — Design system and storefront skeleton

Read the design and localization documents. Build a distinctive, responsive light-theme storefront skeleton using the approved Tooly logo if available.

Implement:
- Tokens, typography setup, buttons, fields, badges, cards, dialogs/drawers, loading/empty/error states
- Responsive header/footer and locale switcher
- Arabic RTL, French LTR, English LTR routing foundation
- Homepage with a unique editorial layout, restrained red accents, category discovery, curated offer section using clearly labeled demo data, how-it-works, FAQs and CTA
- Catalog page and product detail skeleton
- One carefully designed GSAP scroll sequence and one optional 3D/React Bits moment with reduced-motion/static fallback
- No fake reviews, invented live offers, or claims of official affiliation

Use demo content only where necessary and mark it clearly. Test mobile widths and RTL/LTR.
