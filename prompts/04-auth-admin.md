# Prompt 04 — Authentication and admin dashboard

Before coding, confirm the selected authentication/session strategy and admin bootstrap process.

Implement:
- Secure login/logout/session handling through a vetted approach
- Server-side guards and role/permission enforcement
- Protected admin layout and navigation
- Admin CRUD for categories, products, plan variants, localized content, price, availability, and publication state
- Audit trail for sensitive changes
- Form validation, loading/error/empty states, pagination and search
- Tests for unauthenticated, unauthorized, and authorized requests

Do not create a default production admin password or rely on client-side route hiding.
